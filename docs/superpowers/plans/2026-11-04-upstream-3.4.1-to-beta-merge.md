- [ ] **Step 3: 类 B —— 12 个 i18n 源，按「并集优先」解**

文件（12）：
`i18n/i18n-src/{en,ja,ko,pt-BR}/{checkin,routing,settings}.json` 中的 12 个（en/ja/ko/pt-BR 的 checkin·routing·settings + zh-Hant 的 routing，共 12，见附录 A）。

对**每个**文件执行并集合并（保留两边新增键，同键冲突取上游）。脚本内部自行计算 merge-base，可直接运行、无需替换任何值：
```bash
cd /root/programming/github/agent2api/.worktrees/plugin-arch
python3 - <<'PY'
import json, subprocess, pathlib
root = pathlib.Path('.')
mb = subprocess.check_output(
    ['git','merge-base','beta','upstream/main'], text=True).strip()
conf = [l.strip() for l in open('/tmp/opencode/conflict-files.txt')
        if 'i18n-src/' in l]
def show(ref, p):
    r = subprocess.run(['git','show',f'{ref}:{p}'],
                       capture_output=True, text=True)
    return json.loads(r.stdout) if r.returncode == 0 else None
for p in conf:
    base   = show(mb, p)            or {}
    ours   = show('beta', p)        or {}
    theirs = show('upstream/main', p) or {}
    merged = dict(base)
    for k, v in ours.items():   merged.setdefault(k, v)   # 本地新增键保留
    for k, v in theirs.items(): merged[k] = v             # 上游键（含同键）优先
    pathlib.Path(p).write_text(
        json.dumps(merged, ensure_ascii=False, indent=2) + '\n',
        encoding='utf8')
    subprocess.run(['git','add',p], check=True)
    print('merged', p, 'keys=', len(merged))
PY
```
